# ZENITH V3 Concentrated Liquidity AMM Specification

## 1. Overview

Zenith V3 provides concentrated liquidity market making, allowing liquidity providers to allocate capital within customized price intervals $[\text{tickLower}, \text{tickUpper}]$.

## 2. Core Contracts

- `ZenithV3Factory.sol`: Deploys concentrated liquidity pools parameterized by token pair and fee tier.
- `ZenithV3Pool.sol`: Core state machine maintaining initialized tick bitmaps, $Q64.96$ square root price `slot0.sqrtPriceX96`, position records, and fee growth globals.
- `ZenithV3PositionManager.sol`: ERC-721 tokenized LP positions managing minting, liquidity modification, and fee harvesting.
- `ZenithV3Router.sol`: Optimized single-hop and multi-hop execution router.

## 3. Mathematical Architecture

### Price and Tick Relationship:
$$\sqrt{P} = 1.0001^{\text{tick} / 2}$$
$$\text{sqrtPriceX96} = \lfloor \sqrt{P} \cdot 2^{96} \rfloor$$

### Continuous Swap Step Loop:
1. Determine swap direction (`zeroForOne = tokenIn < tokenOut`).
2. Identify next initialized tick using bitwise searching on `TickBitmap`.
3. Compute target square root price $\sqrt{P}_{\text{target}}$ at the tick boundary.
4. Execute `computeSwapStep` to find $\Delta \text{amountIn}$, $\Delta \text{amountOut}$, and fee.
5. If tick is crossed:
   - Transition tick state.
   - Apply `liquidityNet` from crossed tick.
   - Update fee growth trackers.
6. Continue until amount specified is exhausted or slippage limit is reached.
