# ZENITH V2 AMM Specification

## 1. Overview

Zenith V2 extends constant-product liquidity with configurable fee tiers and protocol treasury splits.

## 2. Core Contracts

- `ZenithV2Factory.sol`: Deploys pools with explicit fee tiers (5, 30, 100 BPS).
- `ZenithV2Pool.sol`: Executes swaps enforcing the pool's designated fee tier and directs protocol fees to `ZenithTreasury`.
- `ZenithV2Router.sol`: Multi-hop router with fee path routing (`uint24[] feePath`).

## 3. Supported Fee Tiers

- **5 BPS (0.05%)**: Designed for correlated assets and stable pairs (e.g. USDC/USDT, DAI/USDC).
- **30 BPS (0.30%)**: Standard volatility pairs (e.g. ETH/USDC, BTC/ETH).
- **100 BPS (1.00%)**: Exotic and high-volatility pairs.

## 4. Fee Split Mechanism

$$\text{Total Fee} = \text{amountIn} \times \frac{\text{feeBps}}{10,000}$$
$$\text{Protocol Share} = \text{Total Fee} \times \frac{\text{protocolFeeBps}}{10,000}$$
$$\text{LP Share} = \text{Total Fee} - \text{Protocol Share}$$
